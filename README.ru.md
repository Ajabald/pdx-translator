# PDX Translator

*[In English](README.md) · [简体中文](README.zh-CN.md)*

Оффлайн-приложение для перевода локализаций модов игр Paradox — рабочее место
переводчика, а не пакетный конвертер: таблица строк со статусами, память
переводов, глоссарий терминов, сравнение версий мода и настраиваемая проверка
разметки.

Поддержаны восемь игр серии и своя игра свободным именем. Игра и языки
выбираются при создании проекта.

> Версия 0.1.1. Интерфейс на английском, русском и упрощённом китайском — язык
> выбирается в «Файл → Параметры» и применяется на лету.

## Возможности

- **Проект — отдельный файл** (`*.pdxproj`): все строки, переводы, память и
  архив внутри. Можно положить куда угодно, скопировать, передать другому.
  На экране «Проекты» его можно показать в проводнике, убрать из списка
  (`Delete`) или удалить вместе с файлом (`Shift+Delete`) — удаление уходит
  в корзину, так что промах поправим.
- **Восемь игр серии**: Crusader Kings III, Crusader Kings II, Europa
  Universalis IV, Europa Universalis V, Hearts of Iron IV, Stellaris,
  Victoria 3, Imperator: Rome — и «своя игра» свободным именем, если формат тот
  же, а игры в списке нет. У Crusader Kings II формат старый, CSV: он
  опознаётся по данным, а не по имени файла. У каждой свой набор языковых папок, так
  что нельзя выбрать язык, которого в этой игре не бывает. Проекты и базы
  памяти лежат по загонам (`Projects\CK3`, `Bdd\CK3`): ванильные строки CK3 не
  должны подсказываться переводчику Victoria 3.
- **Обновление мода**: после сканирования видно, что изменил автор — сводка с
  разбивкой на смысловые и косметические правки, колонка «Δ» в таблице,
  подсветка изменённых слов прямо в поле оригинала и история его редакций.
  Косметические правки (пунктуация, регистр, пробелы) можно подтвердить пачкой
  одним действием, а любую операцию — откатить (Ctrl+Z).
- **Память переводов** с подключаемыми базами (`*.pdxtm`) в папке `Bdd`:
  база ванильной локализации игры, перевод основного мода, экспорты других
  проектов. Совпадения подставляются автоматически. Свои записи можно
  просматривать, править и удалять («Инструменты → Память переводов…», F9 — вкладка «Записи»).
- **Похожие строки, а не только точные совпадения.** Панель подсказок
  показывает записи, отличающиеся на слово-два, с процентом сходства и
  подсветкой различий — при переводе сабмода поверх мода точных совпадений
  почти нет, а похожих сколько угодно. Плюс поиск «Как переводили это раньше…»
  (Ctrl+Shift+F) по выделенному куску оригинала: так проверяется, как уже
  переводили имя или оборот. Индекс живёт внутри базы; для баз, собранных
  прежними версиями, он строится кнопкой на вкладке «Базы» окна памяти
  переводов.
- **Глоссарий терминов: статистика предлагает, вы подтверждаете.**
  «Инструменты → Глоссарий…» (Shift+F9) считает совстречаемость слов по памяти
  переводов — собственной памяти проекта и всем подключённым базам — и
  предлагает пары вроде `Maester → мейстер` с уверенностью и числом пар, на
  которых она посчитана. Русские словоформы группируются по основе, поэтому
  «Таргариен» и «Таргариенов» складывают вес, а не делят его; двусловные
  термины тоже находятся. Само по себе в перевод не попадает ничего: каждого
  кандидата вы принимаете или отклоняете, и отклонённый больше не предлагается.
  Принятые термины подсвечиваются в поле оригинала — при наведении виден их
  перевод. Подробности — в разделе [Глоссарий](#глоссарий).
- **Машинный перевод** шестью способами — DeepL, Claude, OpenAI, Google Cloud
  Translation, Yandex Translate и вручную через любой веб-переводчик, если
  ключа нет. Разметка прячется от сервиса и возвращается на место, результат
  получает отдельный статус «Машинный (не проверен)» и обязательно проходит
  проверку качества. Подробности — в разделе [Машинный перевод](#машинный-перевод).
- **Редактор**: правка прямо в ячейке или в нижней панели, подсветка разметки
  CK3 (`[GetTrait…]`, `$VAR$`, `#bold…#!`, `@gold!`), дерево файлов с
  прогрессом, массовые операции, регистронезависимый поиск.
- **Рабочее место**: панель инструментов с частыми действиями, языки проекта и
  подключённые базы памяти всегда видны в шапке (базы включаются оттуда же в
  один клик), светлая и тёмная темы с переключением на лету. Каждая кнопка
  панели имеет пункт меню с той же клавишей, поэтому всё достижимо и мышью, и с
  клавиатуры; настройки собраны в «Файл → Параметры…».
- **Сортировка колонок**: клик по заголовку — по возрастанию, второй — по
  убыванию, третий возвращает исходный порядок (файл и номер строки). Активна
  всегда одна колонка. У колонки «!» второй клик не переворачивает порядок, а
  оставляет только строки с замечаниями — это тот же фильтр, что чекбокс «с
  замечаниями» и пункт «Фильтры → Только с замечаниями».
- **Проверка качества, которую можно настроить под себя**: замечания видны
  сразу в колонке «!» рядом со строкой — потерянные переменные `$…$` и иконки
  `@…!`, разошедшиеся с оригиналом теги, расхождение переносов `\n`, двойные и
  краевые пробелы, пропущенный пробел перед подстановкой (`дома[GetPlayer…]` —
  в игре «домаСтарк»), калька с английской связки (`склонны быть [GetTrait…]` —
  в игре «склонны быть Верность», потому что CK3 называет черты
  существительными), непарные кавычки, один оригинал с разными переводами.
  Любое правило включается, приглушается до предупреждения или получает
  послабления; свои правила добавляются шестью видами проверок, а набор
  целиком передаётся другому переводчику одним файлом. Подробности — в разделе
  [Настройка проверок](#настройка-проверок). Ложное срабатывание помечается как
  «не ошибка» и больше не показывается; полный отчёт по проекту — F6.
- **Загрузка перевода из мода** отдельной командой («Файл → Загрузить перевод
  из мода…»): принять чужой перевод этого мода или свои правки, сделанные прямо
  в файлах. Правила приёма (только пустые строки или с перезаписью, пропускать
  ли строки, где перевод совпадает с оригиналом) видно до записи вместе с
  предпросмотром изменений, а вся пачка снимается одним Ctrl+Z.
- **Запись перевода в мод** в формате игры: имя файла и заголовок получают
  нужный язык, UTF-8 с BOM, порядок и комментарии оригинала сохраняются,
  неизменившиеся файлы не перезаписываются. Папка мода запоминается в проекте
  отдельно от папки, откуда перевод импортировали, а прежние версии
  перезаписанных файлов складываются в `backups` — вне дерева локализации,
  иначе игра прочитает копии наравне с настоящими файлами.

## Установка и запуск

Собранная версия (Windows) — распакуйте архив и запустите `pdx-translator.exe`.
Python не нужен; папки `Bdd` и `Projects` приложение создаст рядом с собой,
то есть его можно держать хоть на флешке.

Из исходников (нужен Python 3.11 или новее):

```
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe -m pdxloc
```

Либо двойным кликом по `run.bat`. Сборка портативной версии:
`.venv\Scripts\pyinstaller.exe pdx-translator.spec` — результат в `dist`.

## Быстрый старт

1. **Создать проект**: выбрать игру, указать папку оригинала (где лежат
   `*_l_english.yml`), папку перевода и языки.
2. **F5** — сканирование: строки попадут в таблицу.
3. Перевести: двойной клик по ячейке перевода или правка в нижней панели.
   `Ctrl+Enter` — сохранить и перейти к следующей непереведённой.
4. **Ctrl+E** — записать перевод в мод: указать папку мода. Выбранная папка
   запомнится в проекте и будет предложена в следующий раз.

## Базы памяти переводов

Моды копируют сотни строк из ванильной игры и из модов, на которых основаны, —
поэтому первое, что стоит сделать, это собрать базы:

- **ваниль**: «Память переводов → Собрать базу», папки
  `…\Crusader Kings III\game\localization\english` и `…\localization\<ваш язык>`,
  тип «База игры»;
- **основной мод, если переводите сабмод**: папка локализации самого мода и
  папка его перевода (обычно это отдельный мод в воркшопе, файлы лежат в
  `…\localization\<язык>`), тип «Импорт чужого перевода».

Готовые базы вместе с приложением **не поставляются**: это чужая локализация —
Paradox и авторов переводов. Инструмент собирает их из вашей копии игры и ваших
подписок за секунды, и это единственный законный способ ими пользоваться.
Собранные базы включаются на вкладке «Базы» того же окна или прямо в
шапке окна.

## Глоссарий

Мод выдумывает свои имена, и весь смысл глоссария в том, чтобы одно и то же имя
переводилось одинаково и на первой странице, и на четырёхсотой. Составлять такой
список руками — скучная половина работы, поэтому «Инструменты → Глоссарий…»
(Shift+F9) предлагает его по тому, что уже переведено.

- **Кандидаты** считаются по памяти переводов коэффициентом Дайса: слово
  оригинала и слово перевода, которые раз за разом попадаются в одних и тех же
  строках, скорее всего и есть перевод друг друга. У каждого кандидата видно
  уверенность и число пар, на которых она посчитана, — сразу понятно, на чём
  держится число.
- **Статистика только предлагает.** Пока вы не приняли кандидата, он ничего
  никуда не пишет, а отклонённый не предлагается снова при следующем прогоне:
  ваше «нет» — тоже данные.
- **Принятые термины подсвечиваются** в поле оригинала, при наведении виден
  принятый перевод. Подсветка уживается с подсветкой изменений на устаревшей
  строке, и каждая выключается своей галкой.
- **Термин можно завести руками** на вкладке «Термины» — то, что никто не
  предлагал, подтверждать не в чем.
- **Галка «только имена собственные»** включена по умолчанию: предлагаются
  только слова, написанные с заглавной посреди фразы. Это и отличает
  `Targaryen` от `Now` — с заглавной попадаются оба, но посреди предложения
  стоит только первый. Снимите галку — и в список добавятся верные, но
  бесполезные пары вроде «Now → теперь».

Три вещи, которые счёт умеет, а наивный подсчёт слов — нет: русские словоформы
группируются по основе («Таргариен» и «Таргариенов» складываются, а не делятся),
двусловные переводы находятся (`Kingsguard` → «Королевская гвардия»), а слова,
которые просто ходят рядом, отсеиваются — настоящий термин выигрывает свой
перевод с отрывом, шаблонный шум нет.

## Машинный перевод

Сервис выбирается в «Файл → Параметры → Машинный перевод». Строку переводит
Ctrl+M, пачку строк — «Инструменты → Машинный перевод…».

| Способ | Нужен ключ |
|---|---|
| DeepL | да |
| Claude | да |
| OpenAI | да |
| Google Cloud Translation | да |
| Yandex Translate | да (плюс идентификатор каталога) |
| Вручную через веб-переводчик | нет |
| Выключено | — |

Ручной способ — для тех, у кого ключа нет: приложение собирает строки с
нумерованными разделителями, вы вставляете этот текст в любой веб-переводчик и
возвращаете результат назад.

Что важно знать:

- **Разметка прячется от сервиса.** Каждый тег заменяется меткой и после
  перевода возвращается на место; потерянные метки попадают в отчёт, а не
  в файлы мода.
- **Пачка либо применяется целиком, либо не применяется вовсе.** Если ответ
  сервиса не удалось разобрать, ни одна строка из пачки не будет записана —
  сдвиг на одну позицию испортил бы весь блок незаметно.
- **Результат помечен «Машинный (не проверен)».** Такой перевод не попадает в
  память переводов, не уходит в мод без явной галки, обязательно проходит
  проверку качества и перестаёт быть машинным, как только строку тронул человек.
- **Ключ хранится в настройках Windows, защищённый DPAPI** (`CryptProtectData`).
  Это закрывает его от чужих глаз в реестре и делает бесполезным перенос куста
  на другую машину, но **не** защищает от программы, запущенной под вашей же
  учётной записью. Расход у платных сервисов считается по символам — размер
  пачки и пауза между запросами настраиваются там же.

## Настройка проверок

«Проверки → Настроить проверки…» (Shift+F6). Что считать ошибкой, зависит от
мода, языка и стадии работы, поэтому набор правил — не константа:

- **17 встроенных правил**. У каждого настраиваются включение, серьёзность
  (ошибка или предупреждение) и послабления — например, какие обёртки для
  склонения не считать расхождением скобок.
- **Свои правила** шести видов: сверка набора токенов, счёт вхождений,
  регулярное выражение по переводу, по паре «оригинал — перевод», парность
  символов и запрещённые символы. Своё правило настраивается целиком, вместе
  с текстом сообщения и примерами.
- **Семь готовых наборов**: «Строгий», «Только поломки», «Свой» и по одному на
  игру с языком — «CK3 · русский», «HOI4 · русский», «CK2 · русский»,
  «Stellaris · русский». Разница не косметическая: на живом переводе в
  136 113 строк строгий набор даёт 41 713 замечаний, встроенный по умолчанию —
  37 040, «CK3 · русский» — 12 591, «Только поломки» — 11 404 (замер 2026-08-10).
- **Три слоя настройки**: встроенные значения, глобальный файл `qa_rules.json`
  рядом с приложением и настройка внутри самого проекта. Каждый слой хранит
  только отличия, поэтому обновление приложения не затирает вашу настройку.
- **Обмен набором** — кнопки «Импорт…» и «Экспорт…» в том же окне, файл
  `.pdxqa`. Так команда договаривается, что считать ошибкой. Файл
  самодостаточен: в нём и выбранный набор, и отличия от встроенных правил, и
  свои правила целиком.

## Статусы строк

| Статус | Цвет | Значение |
|---|---|---|
| Не переведено | красный | нет перевода |
| Машинный (не проверен) | песочный | перевод сервисом, человек его не видел |
| Авто | жёлтый | подставлено из памяти переводов, требует проверки |
| Переведено | зелёный | перевод сохранён |
| Проверено | тёмно-зелёный | перевод подтверждён вручную |
| Устарело | оранжевый | оригинал изменился после перевода (виден дифф) |
| Игнорировано | серо-голубой | переводить нечего (например, строка из одних тегов) |
| Кастомный | фиолетовый | пользовательская пометка |

Процент считается как переведённые и проверенные строки от всех строк, кроме
игнорируемых. Переводы ключей, исчезнувших из оригинала, не пропадают — они
уходят в «Проект → Архив старых переводов…».

## Как устроены файлы

```
pdx-translator/
├─ Projects/       проекты (*.pdxproj) — по одному файлу на мод, по папке на игру
│  └─ CK3/
├─ Bdd/            базы памяти переводов (*.pdxtm) — тоже по папке на игру
│  └─ CK3/
├─ backups/        прежние версии файлов, перезаписанных при записи в мод
│                  (снимки называются по времени; всё остальное, что вы туда
│                   положите, не трогается)
├─ qa_rules.json   глобальная настройка проверок
├─ pdx-translator.log   диагностический лог — приложите его к сообщению об ошибке
└─ pdx-translator.exe
```

Это портативная сборка. При запуске из исходников раскладка та же, только без
`.exe`: запускает `run.bat` — ярлык для `.venv\Scripts\pythonw.exe -m pdxloc`.

Источник истины — файл проекта, а не yml. Правки в yml-файлах вручную
подхватываются при сканировании, но при расхождении побеждает проект (о таких
случаях сообщает отчёт сканирования).

## Командная строка

```
python -m pdxloc --project Projects\Mod.pdxproj --scan
python -m pdxloc --project Projects\New.pdxproj --create "Имя" "путь\english" "путь\russian"
```

## Разработка

```
.venv\Scripts\python.exe -m pip install --group dev
.venv\Scripts\python.exe -m pytest -m "not realdata"
```

Тесты с меткой `realdata` идут по настоящим деревьям локализации; путь к ним
задаёт переменная `PDXT_REALDATA`, и в CI они исключены. Тесты интерфейса
работают без экрана — `QT_QPA_PLATFORM=offscreen`.

После правки строк интерфейса переводы пересобираются:
`.venv\Scripts\python.exe tools\i18n.py all`.

Сборка портативной версии: `pyinstaller pdx-translator.spec`.
